WEB ÔN THI CNTT CƠ BẢN

Mở index.html bằng trình duyệt để sử dụng. Đây là website tĩnh, chạy offline, không cần cài đặt.
Để đưa lên Internet miễn phí: tạo repository GitHub, tải index.html lên, vào Settings > Pages > Deploy from a branch > chọn main / root > Save. Sau khi GitHub Pages xuất bản, dùng đường dẫn mà GitHub cung cấp.

Lưu ý: câu hỏi và đáp án được trích từ PDF; một số câu có hình minh họa trong PDF có thể không hiển thị đầy đủ trong bản web. Hãy đối chiếu tài liệu gốc khi gặp câu hỏi phụ thuộc hình ảnh.
